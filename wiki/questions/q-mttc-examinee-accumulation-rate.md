**Asked by:** the committee and OEE, in [[2026-04-mttc-meaningfully-different-forms]].

The committee's form: "How long does it take to get the number of examinees, as this would
impact the usefulness and accuracy of the results for equating?"

OEE's form: "What numbers make sense so that you can get 100 examinees per year. What's the
number you need for the next groups?"

**Answer given:** none recorded.

**Why it matters.** It is the missing input to nearly every decision in the session. Whether
[[rec-mttc-two-year-escalation]] is a reasonable rule or a dead letter depends on the actual
accumulation rate by field; so does whether
[[rec-mttc-michigan-specific-incidence-categories]] can be drawn sensibly. OEE's strategy already
includes "examining volume to determine how many candidates take the exam each year," so the data
exists or can be produced.

**Asked by:** the committee, in [[2026-04-subtest-performance-indicators]]:

> Correlation between subtests are all the same because real data wouldn't show this. You only
> have three points in the plot – would it make a difference if you didn't have the same
> correlation between the three?

And, separately: "Why is life science different than the others; are other subtests more related
to the total score?"

**Answer given:** none recorded.

**Why it matters.** Batch 1 imposes a single correlation value across all three subtest pairs —
0.65, 0.70, or 0.75 — which real data would not produce. If the true correlation structure is
asymmetric, the simulation may be systematically favourable to whichever method handles symmetric
dependence better, and the uniform CT-PO advantage in
[[ct-po-vs-sbac-simulation-deck]] would need re-testing.

This is the same objection as [[rec-subscore-model-joint-density]] arriving from a different
direction, and it is why [[rec-subscore-review-item-parameters]] was set as a precondition for a
third batch.

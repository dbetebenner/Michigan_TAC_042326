**The advice.** "Start with standard setting form – one set of scorable items and one set of
non-scorable items (20 items). Once one test form has been administered to enough candidates,
start production of next test form. Once non-scorable items are working enough, they go to
scorable."

**Why.** A concrete build sequence that resolves the low-incidence bind without waiving the
100-examinee equating threshold. Every administration does double duty: it produces scores from
the scorable set and simultaneously field-tests twenty embedded items. Item statistics
accumulate at the same rate examinees do, so the pool grows as a by-product of operating the
programme rather than requiring a separate field test that low-incidence fields cannot fill.

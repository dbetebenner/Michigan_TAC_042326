**The advice.** Build a tool into which a district or school could insert a theta value
directly.

**Why.** Raised immediately after the request for the formula, and it is the same request in
executable form. A table discretises a continuous mapping into grade-by-performance-level
cells; a tool would give the concordant score for an actual student rather than the range for
the band that student falls in. It also removes the risk of a district reading the wrong row.

**Status.** Open. Noted as a possibility in the room, not committed.
